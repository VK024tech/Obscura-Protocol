# Obscura Protocol

## A ZK-proof based Privacy Protocol

Obscura Protocol is a zero knowledge privacy protocol built on Ethereum that enables unlinkable ETH transfers.

## Features:
-Fixed denomination privacy pool (1 ETH)
-zk-SNARK verification using Groth16
-Merkle tree-based commitment storage
-Nullifier-based double-spend prevention
-Encrypted withdrawal notes
-IPFS-based decentralized note storage
-On-chain proof verification
-Complete deposit → withdraw unlinkability
